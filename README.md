# WasteWave

### A Real-World Microwave Reflection Dataset for Waste Material Classification

WasteWave is a microwave reflection dataset developed to support research on automated waste material classification using machine learning.

The dataset was collected using a dedicated microwave measurement system consisting of a vector network analyzer (VNA) and two directional antennas.

## Dataset Overview

WasteWave comprises 1,112 microwave reflection measurements collected from 97 unique waste items representing three recyclable material classes.

| Material | Number of Measurements |
|---|---:|
| Metal | 373 |
| Plastic | 375 |
| Cardboard | 364 |
| **Total** | **1,112** |

Measurements were acquired over a frequency range of 863–879 MHz using 101 frequency points.

Each measurement includes complex-valued S-parameters (S11 and S21), represented by their real and imaginary components.

## Dataset Availability

The dataset is available in the `data/` directory of this repository.

The metadata.text provides the data description.

## Research Applications

WasteWave is intended to support research on microwave-based material identification, machine learning benchmarking, automated waste sorting, and multimodal sensing.
